# Sample ETF Rotation Walkforward Report

Generated by `scripts/walkforward_etf_rotation_strategy.py` against the
committed 4-year ETF price matrix at `data/etf_backtest/etf_prices_4y.csv`.
This is **real historical data** (not synthetic), spanning the configured
default universe (`159985 / 512400 / 510300 / 518680 / 513130`).

## Why this report exists

The single-window v0.1 backtest (`docs/sample_etf_rotation_backtest.md`,
commit `840addf`) showed +6.37% return / Sharpe 1.33 / MaxDD 5.38% on the
2024-09 → 2024-12 window — but underperformed naive equal-weight
buy-hold (+12.02%) over the same window. That's **one data point**. It
left an honest caveat on the table: *"this is ONE 4-month window;
walkforward across multiple periods would give a multi-period view"*.

This report is that walkforward. Same harness, same price matrix, same
strategy config — rolled across **14 overlapping 3-month windows
stepping by 1 month** from 2024-01 through 2025-04. The aggregate stats
below answer the question the single-window backtest couldn't: *does the
strategy show consistency, or is the v0.1 result just one tape regime?*

## Reproduce

```bash
python scripts/walkforward_etf_rotation_strategy.py \
    --prices-csv data/etf_backtest/etf_prices_4y.csv \
    --start-date 2024-01-01 \
    --end-date 2025-04-30 \
    --window-months 3 \
    --step-months 1 \
    --output-md docs/sample_walkforward_report.md \
    --output-json output/walkforward_2024-2025.json
```

Add `--enable-policy-signal` to A/B the policy factor across the same
set of windows. The backend endpoint (`POST /etf-rotation/walkforward`)
takes the same parameters in JSON.

## Honest reading of the numbers

* **The strategy beats zero in most windows (9/14 ≈ 64%), but loses to
  buy-hold *on average*.** Mean window return is +2.20% vs buy-hold's
  +5.05% mean per window. The single-window backtest's "lower return,
  lower drawdown" finding holds up at the multi-window level: mean
  drawdown is 4.62%, the worst-window drawdown is 6.74% — both
  meaningfully below the dispersion you'd expect from holding the
  universe outright.
* **Consistency score is 0.213** on a 0-to-1 scale. Read this as
  "the strategy is *directionally* positive most of the time but with
  enough per-window dispersion (std 4.45 pp on a mean of 2.20 pp ≈ CV
  of ~2) that you can't lean on any single window's number". The 64%
  positive-window rate is the headline; the 0.213 score discounts it
  for noise.
* **The worst windows (#5, #10, #11) all hit during sideways/choppy
  tape.** Windows 5 (May–Jul 2024), 10 (Oct–Dec 2024), and 11
  (Nov 2024–Jan 2025) returned −3.18%, −5.13%, and −3.26% respectively
  — exactly when buy-hold was also down or flat. The strategy isn't
  hiding regime risk; it loses money on the same downs as the index.

## Bottom line

The walkforward confirms the v0.1 backtest's "real but modest edge"
verdict: the strategy survives across most rolling windows but does NOT
consistently beat naive buy-hold once you average across regimes.
**Value-add remains drawdown control, not return enhancement** —
upstream production decisions should be sized to that reality, not to
the single +6.37% number from the v0.1 window.

3 bps/side, spread 5 bps half, impact 0.5 bps/%ADV above 5%, commission

| Mean max-drawdown | 4.62% | **4.71%** |
| Worst-window drawdown | 6.74% | **6.89%** |
| Mean per-window TC cost | 0 | **0.29% (~24 bps/window)** |
| Annualised TC drag | 0 | **1.22%** |

The cost layer **does not flip the directional verdict**: 9 of 14
windows are still positive net, the mean window return still beats
zero (+1.96%), and the strategy still meaningfully trails the +5.05%
mean per-window buy-hold benchmark. The annualised TC drag (~1.2%)
matches the ~1.4% total drag observed in the same-window
multi-strategy report — directly attributable to the 7.55%
per-rebalance turnover and the universal 5 RMB CN broker floor.
