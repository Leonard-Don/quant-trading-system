# Sample ETF Rotation Backtest Report

Generated by `scripts/backtest_etf_rotation_strategy.py` against the
committed 4-year ETF price matrix at `data/etf_backtest/etf_prices_4y.csv`.
This is **real historical data** (not synthetic), spanning the configured
default universe (`159985 / 512400 / 510300 / 518680 / 513130`).

The window below is the last quarter of 2024 — chosen because it includes
both the early-October rally and the November-December chop, so the
backtest exercises trend-on and trend-off regimes within a single
3-to-4-month run.

## Reproduce

```bash
python scripts/backtest_etf_rotation_strategy.py \
    --prices-csv data/etf_backtest/etf_prices_4y.csv \
    --start-date 2024-09-01 \
    --end-date 2024-12-31 \
    --output-md docs/sample_etf_rotation_backtest.md
```

Add `--enable-policy-signal` to A/B the policy factor in the same window.

## Honest interpretation

In this 4-month window the rotation strategy **underperformed the naive
equal-weight benchmark** in raw return (+6.37% vs +12.02%) but with
materially less drawdown (5.38% vs ~6.0% for the equal-weight basket
during the Nov-Dec retracement). Sharpe of 1.33 is healthy for the
window length but is **not** robust evidence of edge — a single quarter
is too noisy. Use the walk-forward harness
(`scripts/walkforward_etf_rotation.py`) for cross-regime evaluation.

The 5.98% avg turnover is well within tolerance for a 5-day rebalance
cadence on CN ETFs. In live trading at this turnover the 0.02% one-way
commission would shave roughly 0.6% off the annualised return — leaving
the strategy still positive but materially closer to the benchmark.

Caveats above are intentionally exhaustive: this v0.1 harness exists to
answer "does the scoring layer have any signal at all?", not to predict
realised production P&L. Use the live audit log + `compute_attribution`
pipeline for that.
